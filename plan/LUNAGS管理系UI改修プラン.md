# 3. ユーザー管理

対象：

```text
admin/users.html
```

## 3.1 上部統計

ユーザー管理画面の最上部にある総ユーザー等の統計カードに、5つ目の項目として以下を追加する。

```text
管理者モード中
```

管理者アカウントと管理者モードは別物として扱う。

```text
isAdminAccount
    ↓
恒久的な管理者アカウント

adminMode
    ↓
一時的な管理者モード
```

---

## 3.2 ユーザー一覧

一覧表に表示する項目は以下の7項目に固定する。

| 項目 |
|---|
| ユーザー名 |
| メールアドレス |
| ユーザーID |
| 最終ログイン日時 |
| 管理者か否か |
| 状態 |
| 詳細 |

### UID

`UID` は一覧表には表示しない。

`詳細` を押した場合のみ表示する。

---

## 3.3 表の横書き

ユーザー一覧の表はすべて横書きにする。

文字が意図せず1文字ずつ縦方向へ折り返されないようにする。

基本方針：

```css
white-space: nowrap;
```

を利用しつつ、各列の幅を調整する。

---

## 3.4 画面外にはみ出さない

ユーザー一覧がブラウザ画面外へはみ出さないようにする。

方針：

- ページ全体の不要な横スクロールを発生させない
- テーブルをコンテナ内に収める
- 各カラム幅を調整する
- 長いメールアドレス等を適切に処理する
- 詳細ボタンが画面外へ出ないようにする
- サイドバーを含めた実際の表示領域を基準にする
- `admin.html` のレイアウトを基準にする

# 5. システムログ

対象：

```text
admin/logs.html
```

## 5.1 「ユーザー」を「メールアドレス」に変更

監査ログの列名：

```text
ユーザー
```

を、

```text
メールアドレス
```

に変更する。

---

# 6. 「管理者アカウント」イベント

管理者アカウント関連の監査ログでは、実行者と対象を正しく区別する。

現在のように、

```text
ユーザー
kononagi12@gmail.com

対象
kononagi12@gmail.com
```

のように同じメールアドレスになる状態を避ける。

---

## 6.1 通常の管理者アカウント追加

管理者アカウントから別アカウントを管理者として追加した場合：

### ユーザー

```text
admin
```

### 対象

管理者アカウント追加によって追加されたアカウントのメールアドレス。

例：

```text
イベント
管理者アカウント

ユーザー
admin

対象
example@gmail.com
```

---

# 7. 初期管理者設定の例外

`shared/create-initial-admin.cjs` を使って管理者アカウントを設定した場合は、通常の管理者アカウント追加とは別扱いにする。

対象ファイル：

```text
shared/create-initial-admin.cjs
```

## 7.1 ユーザー

```text
初期設定
```

## 7.2 対象

`create-initial-admin.cjs` で設定されたメールアドレス。

例：

```text
イベント
管理者アカウント

ユーザー
初期設定

対象
initial@example.com
```

# 9. 分析

対象：

```text

```

## 9.1 上部統計カード

現在の、

```text
総ユーザー
30日アクティブ
管理者アカウント
管理者モード中
```

から、

```text

```

を削除する。

```text
総ユーザー
管理者アカウント
管理者モード中
```

例：

```text
┌────────────┐ ┌──────────────┐ ┌──────────────┐
│ 総ユーザー │ │ 管理者アカウント │ │ 管理者モード中 │

```

# 11. 管理イベント集計

「管理イベント集計」は以下の4項目に変更する。

```text
管理者アカウント
管理者モード
降格申請
ユーザー数の累積
```

## 11.1 項目の意味

### 管理者アカウント

管理者アカウント関連イベントの集計。

### 管理者モード

管理者モード関連イベントの集計。

### 降格申請

降格申請関連イベントの集計。

### ユーザー数の累積

イベント件数ではなく、ユーザー数の累積値・推移を示す系列として扱う。

# 14. 重要な設計方針

管理者アカウントと管理者モードは混同しない。

```text
管理者アカウント
    ↓
恒久的
isAdminAccount

管理者モード
    ↓
一時的
adminMode
```

今回の画面表示・集計もこの区分を前提にする。
